# STARTUP STORY ─ スタートアップで働く物語

社員5人のスタートアップ「NOVA WORKS」に入社し、KPI設計・MVV策定・評価制度・資金調達、
そして組織崩壊といったハードシングスの選択を重ねながら、自分と会社を成長させていく
ブラウザ向けアドベンチャーゲームです。

## 遊び方

`index.html` をブラウザで開くだけで遊べます(ビルド・サーバー不要)。

```bash
# ローカルサーバーを使う場合(任意)
npx http-server .
```

- テキストボックスをクリック(または Enter / Space)で物語が進みます
- 選択肢によって「資金・事業・士気・文化・成長」の5つのパラメータが変化します(変化量は表示されません。結果で学んでください)
- 選択はフラグとして記録され、後の章の展開・セリフ・分岐ルートが変わります
- 章が進むごとに資金がバーン(消費)されます。資金か士気が尽きるとゲームオーバー
- 「成長」が上がると役職が昇進します(メンバー → リーダー → … → 取締役COO)
- 突発イベントは2枠×各3種からランダム。第10章は選択によって3つの専用ルートに分岐
- 最終結果に応じて IPO / M&A / 堅実経営 / 再出発 のマルチエンディング
- エンディングでは全選択の「経営の振り返りノート」(◎定石 / ○トレードオフ / △劇薬+解説)が表示され、実際の経営理論に基づく学びが得られます
- 本文中の専門用語(ランウェイ、ノーススターメトリック等、約45語)は下線付きで表示され、タップすると解説ポップアップが開きます
- 章の開始時にはタイトルカード演出、選択肢は数字キー(1〜4)でも選べます

## 構成

```
index.html        … エントリポイント
css/style.css     … ビジュアルノベル風UI
js/art.js         … アドベンチャーゲーム風シーンイラスト(SVG)生成
js/scenarios.js   … ストーリー・選択肢・エンディングデータ
js/game.js        … ゲームエンジン(進行・パラメータ・演出)
```
